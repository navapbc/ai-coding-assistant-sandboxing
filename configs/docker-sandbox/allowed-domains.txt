# allowed-domains.txt — the domains apply-policy.sh adds on top of Docker
# Sandboxes' 'balanced' (default-deny) preset. One domain per line; lines
# starting with # are ignored. Changes to this file are code-reviewed.
#
# NEVER add cloud-provider storage domains (*.amazonaws.com, *.googleapis.com,
# *.blob.core.windows.net, *.cloudfront.net) or paste/transfer sites — they are
# multi-tenant endpoints an attacker can receive data on.
#
# github.com / api.github.com are not listed: the 'balanced' preset already
# allows code hosts (confirm with `sbx policy ls`).
